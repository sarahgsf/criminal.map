## Sobre o projeto

O **Criminal Map** é um sistema de investigação criminal que utiliza a estrutura de dados **Hipergrafo** para representar e analisar relações entre suspeitos, evidências, locais e acontecimentos.

## Objetivo

Explorar a aplicação de hipergrafos na organização de informações e na identificação de conexões complexas, demonstrando sua utilização em um cenário investigativo.

## Tecnologias utilizadas

| Tecnologia | Aplicação |
|:---|:---|
| C | Lógica e estrutura de dados |
| HTML5 | Estrutura da interface |
| CSS3 | Estilização |
| JavaScript | Interatividade |
| SVG | Elementos gráficos |

## Funcionamento

O sistema combina uma interface web com um backend desenvolvido em C, permitindo cadastrar, visualizar e analisar elementos e suas conexões por meio de hipergrafos.
